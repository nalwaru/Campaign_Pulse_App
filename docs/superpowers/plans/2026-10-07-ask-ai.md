# Ask AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans for future implementation work. Steps use checkbox syntax for tracking.

**Goal:** Enable natural-language questions about filtered campaign data through OpenAI.

**Architecture:** Python prepares bounded, weighted campaign summaries. Streamlit owns configuration and session chat; the query module owns server-side Responses API calls and safe errors.

**Tech Stack:** Python, Pandas, Streamlit, OpenAI Python SDK, pytest, uv.

**Spec:** [Ask AI design](../specs/2026-10-07-ask-ai-design.md).

**Record status:** Retrospective documentation of the existing implementation, not a plan written or approved before coding. Checked steps describe work present in the repository. Unchecked steps describe verification still outstanding. No commits, deployment or live API validation are implied.

## Global Constraints

- Python `>=3.10`; Streamlit `>=1.30.0`; Pandas `>=2.0.0`; OpenAI SDK `>=3.26.0`; package manager `uv`.
- Default model: `gpt-4o-mini`.
- Credentials remain server-side; never commit or log API keys.
- Metrics are ratios of sums, never means of row ratios.
- Each breakdown includes at most 100 rows by default; platform and campaign labels are limited to 200 characters.
- Questions are limited to 2,000 characters; retain at most six conversation messages and transmit at most 4,000 characters per history message.
- Responses are capped at 1,000 output tokens; SDK timeout is 30 seconds with one retry for eligible transient errors.
- Set `store=False` on Responses API requests. This is not a zero-retention guarantee.
